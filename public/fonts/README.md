# Website fonts

Self-hosted WOFF2 fonts, with Latin, Latin Extended and Vietnamese subsets:

- Be Vietnam Pro: body text and controls, upright 400–800 and italic 400–600.
- Noto Serif: headings and quotations, variable weight 400–900, upright and italic.

Source: Google Fonts CSS API and fonts.gstatic.com, downloaded 2026-10-21.
Upstream families and licenses:

- https://github.com/google/fonts/tree/main/ofl/bevietnampro
- https://github.com/google/fonts/tree/main/ofl/notoserif

Both families use the SIL Open Font License. The corresponding OFL files are
included in this directory. Font declarations are in `src/styles/fonts.css`.
